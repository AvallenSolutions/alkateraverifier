Do's and Don'ts

✓ Do

  • Lead with ink and paper; let lime appear once or twice per screen as emphasis.
  • Use the serif for headlines and section titles to reinforce the authoritative voice.
  • Show every verdict with its cited clause and plain-English reasoning attached.
  • Use the semantic finding colours consistently: green conforms, amber minor, red major, blue insufficient.
  • Keep depth flat: borders and spacing first, one soft shadow only for floating layers.

✗ Don't

  • Don't flood the UI with lime or set body text in bright lime (it fails contrast) — use accent-strong.
  • Don't present a tier badge as a decorative score with no visible justification.
  • Don't introduce heavy drop shadows, gradients-for-drama, or marketing hero flourishes.
  • Don't set long-form body copy in the serif, or mix in a second serif.
  • Don't add ad-hoc colours for tiers or states; extend the token set instead.
